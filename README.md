# van-server
server-side rendering for VanJS with file-based routing and client-side hydration.

## Demo :

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/fork/github/zakarialaoui10/van-server/tree/main/demo)


## Install 
```bash
npm i van-server
```

## Features
 - ✅ **Server Side Rendering**
 - ✅ **File Based Routing**
 - ✅ **Client Side Hydration** 
 - ✅ **Supports Dynamic Routes**
 - ✅ **Supports both Sync And Async rendering**
